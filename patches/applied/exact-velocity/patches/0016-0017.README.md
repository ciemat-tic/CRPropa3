# ExactRedshift + ExactFutureRedshift bundle for CRPropa

This bundle adds:

- `ExactRedshift`
- `ExactFutureRedshift`
- tests in `test/testInteraction.cpp`
- a Python example: `python/exact_redshift_example.py`
- a short external note: `docs/Redshift_vs_ExactRedshift.md`

## Apply

```bash
bash scripts/apply_one.sh patches/0016-exact-redshift-and-future.patch
bash scripts/apply_one.sh patches/0017-exactredshift-test-include-cosmology.patch
```

## Validate

```bash
ctest -R testInteraction --output-on-failure
```

If Python bindings are enabled, you can also run:

```bash
python3 python/exact_redshift_example.py
```
